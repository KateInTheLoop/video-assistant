Make room for what the interview needs

The right half is for the candidate's coach answers and notes. The left holds the shared call and its transcript. This explorer tests that arrangement using fictional content and the existing coach's visual styles.

What the current code does

  • panel.css fixes the coach to minmax(360px, 36%) when the call is visible. At the default 1280 px window, that is about 461 px for every text section.
  • The hint has a 55vh height cap (65vh for a career walkthrough). The queue can use another 22vh. The transcript shares whatever vertical space remains.
  • lib/callView.js switches to a stacked layout below 900 px. panel.js supports Hide call and Full screen, but no manual split or saved layout preference.
  • The picture is a muted mirror of the captured tab. Controls and editing remain in the original meeting or whiteboard tab.

Proposed behavior in the live coach

  • Keep a visible preset picker, a column divider and a call/transcript divider. Provide keyboard arrows, size limits, text size, hide/show controls and a reset.
  • Save splits and visibility per preset, plus a shared reading size and the last selected preset. Store display preferences separately from candidate/job context. Keep Current as the initial choice for existing users.
  • Switch layouts by moving the existing transcript container, preserving its DOM, scroll position, call video element and media stream. Layout changes must not restart capture or affect the hint pipeline.
  • Give the answer pane the available height in the new presets. Keep the transcript and question history independently scrollable. Below 900 px, put media above the coach and keep the reading pane full width.
  • Preserve the shared picture's aspect ratio. A small preview is appropriate for conversation; use Whiteboard when shared text or diagrams must be readable. The mirror still cannot accept meeting/whiteboard interaction.

Validate before integrating

Compare a long answer, technical notes and busy captions at 1280×820, 1440×900 and a narrow window. Check 125–150% browser zoom, 20 px text, keyboard resizing, hidden panes and per-preset restoration. In the real extension, verify uninterrupted audio/captions while changing layouts, video-track end and Stop, full screen, restored preferences and Linux/Wayland resizing.

This is a design prototype. Its controls work locally; sample captions are static. Changes to the live extension, media lifecycle and extension storage are still to be implemented and tested.
